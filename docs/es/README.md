## Resumen rápido

EnergyPy es una aplicación de escritorio **multiplataforma** (Windows, macOS, Linux) que combina tres funciones principales:

1. **Monitoreo del sistema en tiempo real** — CPU (con temperatura), memoria, disco, red, batería y procesos.
2. **Control de energía** — Programación de apagado, reinicio, suspensión, hibernación y bloqueo.
3. **Gestor de procesos** — Búsqueda, ordenación, información extendida y finalización de procesos en ejecución.

Está construida con **Tauri v2** (backend Rust) y **SvelteKit 5** (frontend TypeScript), lo que da como resultado un binario pequeño (~22 MB) con consumo de recursos mínimo.
